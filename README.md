# Aniel Next para Windows

Silas Duarte · Distribuição de versões.

## Primeiro uso

1. Baixe o pacote com final **win-x64-portable.zip** na seção Releases.
2. Extraia a pasta completa para um local no qual tenha permissão de escrita.
3. Abra **Abrir Aniel Next.exe**. Não execute dentro do ZIP e não mova apenas o EXE.

Windows 10 versão 2004 ou mais recente / Windows 11, x64. O pacote inclui as dependências .NET e Windows App SDK. Se faltar Microsoft Edge WebView2 Runtime, o iniciador informa e o instalador oficial offline está em `Dependencias`, para instalação autorizada pela TI.

O aplicativo não instala serviços, não solicita privilégios de administrador e não altera políticas de domínio. A execução e as atualizações dependem das permissões da empresa.

## Acesso e dados

Configure a empresa e importe a configuração fornecida separadamente pelo responsável. Este repositório não contém credenciais, configurações privadas nem dados operacionais. Cada usuário precisa de acesso autorizado ao servidor da empresa.

## Atualizar

O aplicativo verifica novas versões ao abrir. Na opção **Atualizações**, baixe a versão disponível e, depois de salvar seu trabalho, clique em **Fechar e atualizar**. A versão anterior é preservada em sua pasta. Os acessos, configurações e rascunhos já salvos permanecem no perfil do Windows.

O arquivo com final **win-x64-update.zip** é usado pelo atualizador. Para começar em outro computador, utilize o pacote portátil completo.
